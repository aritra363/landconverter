# Indian Land Area Converter

A simple and intuitive web application for converting various Indian and global land area units. This tool is designed to be fast, accurate, and easy to use, with a special focus on state-specific units that vary across India.

## Features

*   **State-Specific Conversions:** Accurate conversions for land units like Bigha, Katha, and more, with values adjusted for different Indian states.
*   **Wide Range of Units:** Supports a variety of local and global units, including:
    *   Bigha
    *   Katha
    *   Decimal
    *   Guntha
    *   Cent
    *   Acre
    *   Hectare
    *   and many more...
*   **Multilingual Interface:** Use the app in English, Hindi, or Bengali.
*   **Light & Dark Mode:** Switch between light and dark themes for comfortable viewing.
*   **Dynamic SEO:** Page titles and meta descriptions update dynamically for better search engine visibility.

## How to Use

1.  Open the `index.html` file in your web browser.
2.  Select the state for which you want to perform the conversion.
3.  Enter the land area value in the input field.
4.  Choose the "From" and "To" units from the dropdown menus.
5.  The converted result will be displayed instantly.
